# Guide de Personnalisation des Ordonnances

Ce guide explique comment personnaliser le modèle d'ordonnances médicales dans l'application Cabinet Médical.

## 📋 Fonctionnalités

### 1. Personnalisation du Modèle

Vous pouvez personnaliser les éléments suivants de vos ordonnances :

#### Logo et En-tête
- **Logo** : Upload du logo de votre clinique ou cabinet
  - Formats acceptés : PNG, JPG
  - Taille recommandée : Max 2MB
  - Le logo s'affiche en haut à droite de l'ordonnance

- **Nom du médecin** : Votre nom complet (ex: Dr. Ahmed Benali)
- **Spécialité** : Votre spécialité médicale (ex: Cardiologue, Pédiatre)
- **Nom de la clinique** : Nom de votre établissement (optionnel)
- **Adresse** : Adresse complète du cabinet
- **Téléphone** : Numéro de contact
- **Email** : Adresse email professionnelle

#### Disposition des Informations Patient
Vous pouvez choisir où afficher les informations du patient :
- **En-tête** : Après les informations du médecin (recommandé)
- **Corps** : Avant la prescription

#### Champs Patient Visibles
Activez/désactivez l'affichage de :
- ✅ Nom complet
- ✅ Âge
- ✅ Sexe
- ✅ Date de naissance

#### Couleurs
- **Couleur de l'en-tête** : Couleur principale pour les bordures et titres
- **Couleur d'accent** : Couleur secondaire pour les éléments de mise en évidence

### 2. Accès aux Paramètres

#### Depuis l'Éditeur d'Ordonnances
1. Cliquez sur "Nouvelle Ordonnance"
2. Sélectionnez un patient
3. Cliquez sur le bouton **"Paramètres"** en haut à droite
4. Modifiez les paramètres souhaités
5. Cliquez sur **"Enregistrer comme modèle par défaut"**

### 3. Utilisation du Modèle

Une fois votre modèle configuré :
1. **Création automatique** : Chaque nouvelle ordonnance utilisera votre modèle
2. **Prévisualisation en temps réel** : Voyez les modifications instantanément
3. **Cohérence** : Toutes vos ordonnances auront le même style professionnel

### 4. Export et Impression

#### Export PDF
- Cliquez sur le bouton **"PDF"** pour exporter l'ordonnance
- Le fichier est nommé automatiquement : `Ordonnance_NomPatient_Date.pdf`
- Le modèle personnalisé est conservé dans le PDF

#### Impression
- Cliquez sur le bouton **"Imprimer"**
- L'ordonnance s'imprime avec votre modèle personnalisé
- Format : A4 optimisé pour l'impression

### 5. Médicaments et Prescriptions

#### Ajouter un Médicament
1. **Nom** : Nom commercial ou DCI
2. **Dosage** : Concentration (ex: 1000mg, 5ml)
3. **Forme** : Comprimé, Gélule, Sirop, etc.
4. **Fréquence** : Nombre de prises (ex: 3 fois par jour)
5. **Durée** : Durée du traitement (ex: 7 jours)
6. **Moment de prise** : Avant/après les repas, etc.
7. **Instructions** : Consignes spéciales (optionnel)

#### Gestion des Médicaments
- ✏️ Ajoutez autant de médicaments que nécessaire
- 🗑️ Supprimez un médicament en cliquant sur l'icône rouge
- 👁️ Prévisualisez en temps réel dans le panneau de droite

### 6. Observations

Ajoutez des observations, recommandations ou consignes spéciales :
- Repos recommandé
- Régime alimentaire
- Précautions particulières
- Rendez-vous de suivi

## 🎨 Conseils de Personnalisation

### Pour un Aspect Professionnel
1. **Logo** : Utilisez un logo haute résolution avec fond transparent
2. **Couleurs** : Choisissez des couleurs professionnelles (bleu, vert, gris)
3. **Informations complètes** : Remplissez tous les champs de contact
4. **Cohérence** : Utilisez toujours le même modèle

### Exemples de Couleurs Recommandées
- 🔵 **Médecine générale** : #1e40af (bleu marine)
- 💚 **Pédiatrie** : #059669 (vert)
- ❤️ **Cardiologie** : #dc2626 (rouge)
- 💜 **Psychiatrie** : #7c3aed (violet)

## 🔧 Réinitialisation

Pour revenir aux paramètres par défaut :
1. Ouvrez les **Paramètres d'ordonnance**
2. Cliquez sur **"Réinitialiser"**
3. Confirmez l'action

⚠️ **Attention** : Cette action est irréversible et supprimera toutes vos personnalisations.

## 🆘 Problèmes Courants

### Le logo ne s'affiche pas
- Vérifiez la taille du fichier (max 2MB)
- Utilisez un format PNG ou JPG
- Essayez avec une image de plus petite taille

### Les couleurs ne s'appliquent pas
- Cliquez sur "Enregistrer comme modèle par défaut"
- Rafraîchissez la page
- Réessayez la personnalisation

### L'export PDF ne fonctionne pas
- Vérifiez que tous les médicaments sont ajoutés
- Essayez d'imprimer d'abord
- Contactez le support technique
